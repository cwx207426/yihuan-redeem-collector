# 游戏兑换码搜集器 v3.0 🎮

> 多游戏支持：异环 · 造梦西游OL — 兑换码搜集、验证、追踪

## ✨ 功能

- 🎮 **多游戏切换** — 标签页切换不同游戏，支持动态添加新游戏
- ✅ **已验证有效码优先** — 默认展示社区亲测有效的兑换码，失效码自动排除
- 🔬 **验证体系** — 区分「已验证有效」和「待验证」，避免无效码误导
- 🎨 **暗色主题 GUI** — GitHub 风格深色界面，左侧卡片列表 + 右侧详情面板
- ✔️ **使用追踪** — 标记已使用/恢复，状态持久化到本地（按游戏独立追踪）
- 🔍 **多维度筛选** — 已验证有效 / 待验证 / 已使用 / 失效过期 / 全部
- 📝 **一键复制** — 单个 + 批量复制全部已验证有效码
- ✏️ **手动管理** — 添加/编辑/删除兑换码、标记已验证
- 🕹️ **添加新游戏** — 通过界面动态添加新的游戏数据
- 🔄 **联网验证** — 定期检查来源可访问性
- ⏰ **自动过期检测** — 限时码到期自动标记

## 🚀 快速开始

### 方式一：源码运行

```bash
pip install requests
python app.py
```

### 方式二：自行打包 exe

```bash
pip install pyinstaller requests
python build.py
# exe 输出在 ../dist/YihuanRedeemCollector.exe
```

## 📁 文件说明

```
yihuan-redeem/
├── app.py              # 主程序 GUI (v3.0) — 多游戏支持
├── build.py            # PyInstaller 打包脚本
├── codes_data.json     # 兑换码数据（含验证状态、多游戏结构）
└── .gitignore
```

## 📝 使用说明

1. 运行 `python app.py` 或双击打包好的 exe
2. 顶部标签页切换游戏（异环 / 造梦西游OL）
3. 默认显示「已验证有效」的兑换码（已排除失效码）
4. 点击卡片查看详情，点击「标记已使用」追踪
5. 顶部筛选栏切换视图
6. 「复制全部有效码」批量导出到剪贴板
7. 可通过「+ 添加兑换码」手动录入新码
8. 可通过「+ 添加游戏」添加新游戏数据
